LicenseLanka - mobile app (ongoing)

***Problem Statement***
Many people in Sri Lanka face difficulties when preparing for the driving license written exam because study materials are limited, confusing, or not easily accessible.
Learners also lack a simple way to practice questions and understand road rules before the exam.

****Technplogies Used*** 
Frontend:   React Native 
Backend:    Node.js 
Database:   Supabase
